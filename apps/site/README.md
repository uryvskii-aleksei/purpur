# «Пурпур» — новая версия магазина

Готовый адаптивный интерфейс магазина с приоритетом розницы. Все страницы работают без сборки и без зависимостей. Размещаемая версия находится в `public/`.

## 1. Подарочная розница

Корпоративный пурпурный усилен в `public/brand.css`: основной `#9d169e`, глубокий `#6f267d`, светлый `#f1e5f3`. Пурпурные поверхности используются на первом экране, в разделе начинок и в подвале. Фотографии остаются на светлом фоне. Цвета вынесены в CSS-переменные для точной подгонки под брендбук. Публичный доступ включён по запросу владельца; вход для просмотра не требуется.

Главная построена вокруг подарка из натурального шоколада: ролик фабрики на первом экране с заголовком и кнопкой выбора подарка, затем три оформления одного ассорти. Подарочные наборы доступны до общего каталога. Добавлены четыре начинки, объяснение состава тёмного шоколада, краткие пересказы двух реальных отзывов с датой и источником, рекомендации планировать получение к дате подарка. В карточках можно менять оформление и увеличивать оригинальные фотографии. Количество 8 конфет указано только у «Морской столицы», где оно подтверждено описанием фабрики; для других наборов не выводится. Фотографий в руке, размеров коробки и снимков конфет в разрезе в полученных материалах нет, поэтому они не выдумывались.

## 2. Что работает

Текст увеличен: основные описания 16–18 px, интерфейс 16 px, сведения о фасовке и условиях 14 px. Для телефонов каталог перестроен в одну колонку с фотографией и читабельным текстом рядом. Раздел фильма расположен после подарочных наборов; ссылка на воспроизведение есть на первом экране. Оригинальный 49,56-секундный ролик с главной purpur.spb.ru переиспользован без изменения монтажа и сжат с 47 998 905 до 4 815 561 байт (H.264, faststart). Обложка — реальный кадр на 4-й секунде. На первом экране ролик используется фоном: автоматический запуск без звука, цикл, пурпурное затемнение и отдельная кнопка паузы. Он останавливается за пределами первого экрана и при скрытии вкладки. При reduced-motion остаётся обложка, запуск возможен вручную. Атрибут preload="none" предотвращает предзагрузку до решения JS о воспроизведении. Полная версия ниже запускается по нажатию, с нативными элементами управления и возможностью полноэкранного просмотра; два проигрывателя не воспроизводятся одновременно. Исходный URL: https://purpur.spb.ru/f/2021-11-18_pur_pur_editing_full_dlya_sajta_1.mp4.

- Главная, разделы о фабрике, доставке и оптовом сотрудничестве.
- Каталог 221 товара из всех действующих разделов старого магазина, с фотографиями и ценами. Проверены 60 страниц категорий, включая пагинацию. В 29 карточках нет подтверждённого веса: они доступны для просмотра и уточнения, добавление в заявку отключено до подтверждения фасовки. 14 карточек из карты сайта, отсутствующих в действующих разделах (включая тестовую и служебную), не перенесены. Сверка сохранена в catalog-audit.json.
- Поиск по названию, вкусу и составу, фильтры категорий (включая марципан, шоколад, фрукты, цукаты, десерты), бюджет, сортировка; выдача по 24 товара.
- Подбор подарка по предпочтению и бюджету.
- Карточки с составом, хранением, пищевой ценностью и ссылкой на источник.
- Корзина с изменением количества и удалением. В localStorage сохраняются только идентификаторы товаров и количество.
- Заявка: контактные данные, получение, город/ПВЗ, пожелания, итог товаров и пояснения о доставке. Заявку можно скачать либо открыть в своей почтовой программе и отправить самостоятельно.
- Оптовая форма готовит письмо с условиями и объёмом; предусмотрено скачивание текста письма.
- Клавиатурная навигация, dialog с удержанием фокуса, reduced-motion, мобильное меню.

Фото, описания состава, цены и фасовки получены с публичных страниц purpur.spb.ru 26.10.2026. Индивидуальные ссылки сохранены в `public/products.js`. Позиции без подтверждённого веса видны в каталоге, но исключены из заявки до уточнения фасовки. Цены не синхронизируются автоматически; наличие менеджер подтверждает отдельно. Бесплатная доставка от 10 000 ₽ распространяется на ПВЗ СДЭК по Санкт-Петербургу. Подготовка — 3 рабочих дня. Термокороб может оплачиваться дополнительно.

## 5. Подключение к действующему магазину

Эта версия развёрнута отдельно, доступна по публичной демонстрационной ссылке. Домен purpur.spb.ru и его действующий магазин не изменялись. Онлайн-эквайринг, автоматическая отправка заявок, склад, актуальные остатки и доставка по API не подключены. Формы не имитируют отправку и не записывают заказ на сервер: пользователь явно скачивает заявку либо отправляет её в своей почтовой программе.

Для полноценного запуска на домене необходимы исходники/доступ к CMS существующего магазина, подтверждённые товарные идентификаторы и правила фасовок, API корзины и заказов, платёжный провайдер, доставка и CRM. Каталог и действия корзины изолированы в products.js, store.js и app.js для подключения этих сервисов. Удалить noindex только при публичном запуске после подключения. Аналитика и сторонние трекеры не добавлены.

## 6. Ресурсы

Изображения — публичный сайт фабрики «Пурпур», использованы для её новой версии. Шрифты Manrope и Literata — Google Fonts, лицензии OFL в assets/.

Затемнение видео ослаблено, более плотный пурпур сохранён под текстом. Описания четырёх начинок и примечание об аллергенах имеют один размер 14 px.

## 7. Публикация

Для статического хостинга загрузите содержимое `public/` в корень сайта. Сборка и npm install не нужны. Для Sites сохранена существующая идентичность в `.openai/hosting.json`, каталог публикации — `dist`. Перед обновлением получите актуальные исходники и права через интеграцию Sites, перенесите публикуемые файлы из `public/` в `dist/` отдельного исходного checkout Sites и выполните штатный процесс упаковки и публикации. Не создавайте другой Site и не заменяйте GitHub origin техническим remote сервиса. Публикация исходников в GitHub сама по себе не обновляет размещённый сайт.

Текущая демонстрация: [purpur-chocolate.abuzz-whale-0368.chatgpt.site](https://purpur-chocolate.abuzz-whale-0368.chatgpt.site/). Альтернативный адрес Netlify ранее имел проблемы доступности, поэтому он не считается основной демонстрацией.

## 8. Концепция для бизнеса

Отдельная страница `public/concept/` показывает более светлый и компактный вариант. Исходная главная остаётся доступной для сравнения. Фотографии, фильм, каталог и расчёты используются из тех же источников.

[Опубликованная концепция](https://purpur-chocolate.abuzz-whale-0368.chatgpt.site/concept/). Локальный адрес: [localhost:4173/concept/](http://localhost:4173/concept/). Подарочные наборы, полный каталог, содержимое ассорти, получение и два сценария для бизнеса собраны в короткую последовательность. Новые формы сохраняют черновики в памяти страницы. В постоянное хранилище попадают только ID и количества корзины. После перезагрузки контактные данные не восстанавливаются.

Доступен только результат «Заявка подготовлена». Получение фабрикой, общий реестр, подтверждение менеджера и оплата не имитируются. Целевой первый выпуск и дальнейший онлайн-заказ описаны в [концепции](../../docs/techprojects/site-concept/site-concept.md). Проверки состояния и текста заявок: `node --test tests/concept.test.cjs`.
