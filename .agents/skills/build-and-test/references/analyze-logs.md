# Analyze Logs (Network / Console / HAR)

Use the supplied HAR or the relevant running app through Chrome DevTools MCP. Confirm the active app/tab, then read network requests and console messages. Diagnostics alone does not authorize edits, builds, tests or state-changing API calls.

Correlate HTTP failures, CORS, slow requests and console errors with the expected flow. Report source, useful request/error evidence, expected versus observed behavior and supported conclusions. Redact personal data. Do not save raw HAR/logs unless explicitly requested.
