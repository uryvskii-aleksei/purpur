# UX and visual design

Apply the [designer contract](../../roles/designer.md). Start from the affected journey and existing design rather than a blank redesign.

1. Read users, acceptance, actual UI and factual copy/assets. Resolve only gaps that materially affect the flow. Preserve purple brand identity and verified product photography.
2. Cover relevant default, loading, empty, error, validation, success and recovery states. A real successful operation differs from a local preview or prepared email.
3. Specify responsive layout, readable type, focus order, keyboard/dialog behavior, contrast and reduced motion. Without design integration, use editable local specs/prototypes. A supplied Figma reference follows [figma-to-code](../figma-to-code/SKILL.md).
4. Source copy/assets with content-manager. Hand coder interactions and state boundaries, QA acceptance cases and marketing approved creative. Application-code authorship must be explicitly assigned if included.
5. Inspect relevant rendered states when preview is available. State actual coverage and leave unavailable rendering unverified.

Return editable design/specification, provenance, state behavior and checks. A design handoff does not independently launch product implementation or publication.
