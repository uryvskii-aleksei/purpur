## 2. Цель и полномочия

Приём розничного заказа с текущей оплатой через менеджера. [Владеющий источник](../../docs/site-brief.md). Прямое поручение CTO от 27.10.2026 включает анализ, регистрацию задач и локальную подготовку. Текущая оплата остаётся через менеджера, самостоятельный интернет-магазин — будущий этап. Prod и существующие почтовые настройки пока не меняются. Для настройки нужны фактические полномочия и параметры. Создание записи не оформляет подписку, не меняет доступы и не отправляет сообщения.

## 3. Критерии приёмки

- Розничное обращение/заказ реально зарегистрировано и передано ответственному менеджеру по действующему процессу. Покупатель видит достоверное получение и следующий шаг. Повторы не создают дублей, ошибка сохраняет ввод. Оплата по-прежнему проходит через менеджера, подготовленный текст не выдан за оплату.
