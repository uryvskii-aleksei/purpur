# Что берём без панели действующего сайта

## 1. Решение

28.10.2026 вечером CTO сообщил: панель действующего сайта неудобна, резервную копию из неё не забрать. Дальше состав магазина читается с открытых страниц. Вход в панель, обход её ограничений и изменение `purpur.spb.ru` не делаются. Перенос домена этим решением не начат.

## 2. Уже снято с открытых страниц

26.10.2026 с `https://purpur.spb.ru/magazin` прочитаны 60 страниц категорий. В снимке 221 опубликованная карточка: адрес, название, цена, фасовка, состав и фото. Сверка лежит в `apps/site/catalog-audit.json`. 29 карточек без подтверждённой фасовки в заявку не допускаются. 14 адресов из карты сайта в каталог не вошли. 27.10.2026 отдельно прочитаны главная, регистрация и публичные тексты оплаты и доставки. Это не остатки и не действующая цена на 28.10.2026.

## 3. Чего на открытой странице нет

Заказы, покупатели, остатки, неопубликованные карточки, шаблоны CMS, база, почта и настройки платежа в публичный HTML не входят. Этих данных в Git нет и из панели они не вытаскиваются. Подставлять их по догадке нельзя.

## 4. Как читать страницу

Берётся то, что страница уже отдаёт покупателю: HTML, адреса карточек, текст и файлы картинок. Скрытый вход, чужая сессия и внутренний адрес панели для этого не используются.
