## 5. Результаты и следующий шаг

Результат: три дефекта закрыты проверкой QA, четвёртый после неё поправлен координатором и ждёт повторного взгляда QA. 28.10.2026 перепроверены четыре открытых дефекта на `http://127.0.0.1:4173/concept/`, ветка `feature/site-business-concept`, коммит `c40a70d55e39a46d7e9fd5c581c46f4206514762` и несохранённые файлы концепции, которые отдаёт локальный сервер. Подробности: [перепроверка](artifacts/2026-10-28-concept-recheck.md). Первая проверка того же дня остаётся в [отчёте](artifacts/2026-10-28-concept-check.md) и не считается новым результатом.

Пройдены дефекты 1, 3 и 4. На 390 px ошибка телефона стоит текстом на странице и не закрывает подпись «Как получить». Рамка поля заявки даёт контраст 8,92:1 на белом и 8,79:1 на фоне диалога. «Закрыть карточку» и «Открыть меню» — 44×44 px. Подготовленный текст говорит, что фабрика заявку ещё не получила и демонстрация платёж не проводит. Карта, СДЭК и самовывоз описаны как правила. Экрана списания нет.

Дефект 2 после перепроверки QA оставался: на 195 CSS px документ был 248 px. Координатор сложил на этой ширине подвал, карточки и длинные заголовки в одну колонку. Повторный замер: при 195 и 280 CSS px ширина документа совпадает с окном. Это замер координатора, не новая независимая проверка.

Снимок экрана у QA не получился из-за таймаута. В той перепроверке не проверялись физический телефон, щипок, системная клавиатура, экранный диктор, порядок Tab, кольцо фокуса и Escape у `<dialog>`. Отдельный текст для СДЭК в другой город не собирался. Прежняя витрина и `https://purpur.spb.ru` не открывались.

Автозапуск фильма без reduced motion не дефект. 28.10.2026 CTO задал фоновое видео с паузой. При `prefers-reduced-motion` ролик остаётся на паузе. Прежнее ожидание ручного запуска из UX-анализа это решение не отменяет.

Следующий шаг: независимая перепроверка ширины 195 CSS px. Три остальных дефекта на версии QA закрыты. Автозапуск фона не откатывать. Задачу не закрывать.
