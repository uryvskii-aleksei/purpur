## 2. Цель и полномочия

Будущий интернет-магазин. На текущем этапе оплата остаётся через менеджера. Исследование можно продолжать, но реализация прямой оплаты/телефонного кабинета сейчас не запускается.

Независимая приёмка полной покупки. Основание и предметные сведения: [владеющий источник](../../docs/techprojects/site-development/architecture.md). Поручение CTO от 27.10.2026: формировать и анализировать Git-бэклог, распределять работу и автономно выполнять понятные локальные задачи в заданных границах. Продажи и оплаты целевым образом проходят через сайт, менеджер участвует минимально. Текущий шаг ограничен указанными зависимостями. Изменения Prod, реальные платежи/SMS, публикация, commit/push и слияние не выполняются автоматически.

## 3. Критерии приёмки

- На одной интегрированной версии выполнены первый/повторный заказ, ошибки кодов, чужой заказ, подмена суммы, дубли и потеря ответа, отмена и восстановление. Состояния passed/failed/blocked/not-run имеют доказательства. Code review выполняется отдельно.
