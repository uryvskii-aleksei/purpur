# Матрица приёмки покупки

## 1. Статус

Подготовлена координатором 27.10.2026 по требованиям и анализу. Это план для независимого QA, сценарии не выполнены. Для исполнения нужны точная версия, разрешённый изолированный стенд, синтетические данные и контракт провайдеров.

## 2. Сценарии

| Сценарий | Ожидаемый результат |
| --- | --- |
| Первая покупка | Короткий путь без отдельной предварительной регистрации, достоверная оплата и заказ на сайте |
| Повторная покупка | Проверенный телефонный код даёт доступ только к своему покупателю, актуальные условия пересчитываются |
| Неверный/истёкший/повторный код | Доступ не выдан, определены восстановление и лимиты |
| Перебор/повторная отправка | Защита от злоупотребления и неконтролируемого расхода, без утечки существования аккаунта |
| Чужой customerId/orderId | Сервер отклоняет чтение и изменение без полномочий |
| Смена номера/общий браузер | Применяется согласованный безопасный процесс, история не объединяется по введённой строке |
| Изменилась цена/нет фасовки | Неверная сумма не списывается, неизвестное не подменяется догадкой |
| Двойной клик/две вкладки | Нет повторного заказа и списания, определён конфликт изменённой нагрузки |
| Ответ потерян | Статус восстанавливается по операции, запрос не повторяется вслепую |
| Поддельное/дублированное событие оплаты | Не создаёт подтверждения или повторных побочных действий |
| События не по порядку | Допустимые переходы не откатывают подтверждённый факт произвольно |
| Уход со страницы оплаты | Показано действительное ожидание/отказ/успех по источнику, не по return URL |
| Деньги получены, исполнение невозможно | Согласованный процесс исключения/возврата, без выдуманного резерва |
| Возврат в корзину/ошибка | Выбор и допустимый черновик сохранены |
| Корпоративное обращение | Подтверждено реальное получение, типы подарков/поставок разделены, дубли не созданы |
| Самообслуживание | Разрешённые операции доступны по состоянию заказа, менеджер получает определённые исключения |
| Узкий экран/клавиатура/увеличение | Основное действие и ошибки доступны без потери фокуса и управления |
| Изоляция/восстановление | Тест не затрагивает Prod, синтетический набор восстановим, логи не содержат секретов/кодов/контактов |

## 3. Доказательства

QA фиксирует для каждого сценария passed/failed/blocked/not-run, источник версии и наблюдение. Отдельный reviewer анализирует код и контракты той же версии. Прошедшие локальные unit-тесты не доказывают реальную доставку SMS, оплату или безопасность всей системы.
