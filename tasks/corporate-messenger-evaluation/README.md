# Выбор корпоративного мессенджера

## 1. Карточка

- ID: `corporate-messenger-evaluation`.
- Тип: `research`.
- Статус: `backlog`.
- Приоритет: `P2`.
- Этап: `current`.
- Ответственная роль: `devops`.
- Назначение: Роль отвечает за будущий ограниченный этап. Активный исполнитель не запущен.
- Зависимости: [corporate-tools-plan](../corporate-tools-plan/README.md).

## 2. Цель и полномочия

Выбор корпоративного мессенджера. [Владеющий источник](../../docs/techprojects/site-development/corporate-tools.md). Прямое поручение CTO от 27.10.2026 включает анализ, регистрацию задач и локальную подготовку. Текущая оплата остаётся через менеджера, самостоятельный интернет-магазин — будущий этап. Prod и существующие почтовые настройки пока не меняются. Для настройки нужны фактические полномочия и параметры. Создание записи не оформляет подписку, не меняет доступы и не отправляет сообщения.

## 3. Критерии приёмки

- Проверены потребность и текущие каналы. Rocket.Chat оценён как кандидат по размещению, администрированию, правам, восстановлению и затратам. Есть рекомендация и реальные альтернативы, если они нужны. Развёртывание/покупка не объявлены выполненными.

## 4. План

- [ ] 1. Проверить существующие инструменты, владельцев и ограничения по зависимостям.
- [ ] 2. Подготовить конкретное решение, параметры проверки и необходимые материалы.
- [ ] 3. В разрешённых границах выполнить назначенный этап, проверить результат и сохранить доказательства.

## 5. Результаты и следующий шаг

28.10.2026 вечером CTO решил мессенджер сейчас не выбирать и не ставить. Rocket.Chat остаётся неотмеченным кандидатом. Заявки с сайта идут на почту, не в мессенджер.

Следующий шаг: не разворачивать мессенджер, пока не будет отдельного поручения.
