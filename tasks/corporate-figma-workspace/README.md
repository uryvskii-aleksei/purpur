## 2. Цель и полномочия

Организация корпоративного пространства Figma. [Владеющий источник](../../docs/techprojects/site-development/corporate-tools.md). Прямое поручение CTO от 27.10.2026 включает анализ, регистрацию задач и локальную подготовку. Текущая оплата остаётся через менеджера, самостоятельный интернет-магазин — будущий этап. Prod и существующие почтовые настройки пока не меняются. Для настройки нужны фактические полномочия и параметры. Создание записи не оформляет подписку, не меняет доступы и не отправляет сообщения.

## 3. Критерии приёмки

- Установлены корпоративный владелец/администраторы, участники и права, способ оплаты в пределах согласованного бюджета, рабочая структура файлов и передача владения. В Git есть требования, ссылки на редакции и нужные экспорты с известными ограничениями. Доступ к конкретным файлам проверен после настройки.
