Журнал локального запуска: `/private/tmp/purpur-local-concept.log`, PID-файл: `/private/tmp/purpur-local-concept.pid`. Перед любым завершением процесса нужно проверить, что PID всё ещё относится к серверу этой папки. Для обычного ручного запуска из основной папки используется `npm run dev`. Это локальный просмотр, а не внешний стенд.
