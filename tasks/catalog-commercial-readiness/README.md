Поручение CTO от 27.10.2026: формировать и анализировать Git-бэклог, распределять работу и автономно выполнять понятные локальные задачи в заданных границах. В локальную заявку снимок допускает 192 позиции с непустой фасовкой и `canOrder: true`. Текст состава есть у 189 из них. У id 137, 138 и 139 состава нет. Ограничение заказа сохранено у 29 позиций с пустой фасовкой. Их URL совпали со списком сверки. Строка `sourceWeight` «120» без единицы у id 127, 128 и 129 за фасовку не принята.
