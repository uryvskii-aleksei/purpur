## 2. Цель и полномочия

Разрешена текущая локальная правка интерфейса. Рабочая папка основная, feature/site-business-concept. Источник требований — [бизнес-бриф](../../docs/site-brief.md).

## 3. Критерии приёмки

- Первый экран ведёт в общий каталог, раскрывает ассортимент, каталог расположен сразу после него. Есть видимые входы по всем существующим категориям.
- Все221записи текущего снимка доступны. Сначала показаны24товара разных групп, далее можно загрузить ещё или весь результат. Исходные данные и явная ценовая сортировка сохранены.
- Поиск, фильтры, карточки и корзина работают.29позиций с неподтверждённой фасовкой остаются видимыми с прежним ограничением заказа.
- Данные от26.10.2026 не выдаются за подтверждённое актуальное наличие или доказательство полноты действующего каталога. Оплата сейчас остаётся через менеджера.
