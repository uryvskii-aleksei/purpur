# Локальная доска отдела

## 1. Запуск

Из рабочей папки с реестром `tasks/` выполните `npm run department`. Откройте [127.0.0.1:4174](http://127.0.0.1:4174/). Сайт на порту 4173 продолжает работать отдельно. Для другого порта используйте переменную `PORT`. Node.js 22+, установка пакетов и сборка не требуются.

## 2. Источник и возможности

Доска читает [канонические задачи](../../tasks/README.md) при открытии и по кнопке обновления. Есть фильтры по этапу, роли, приоритету и тексту. Карточка открывает назначения, зависимости, критерии, план, результат и исходную запись. Текущий этап с оплатой через менеджера показан первым. Будущий интернет-магазин доступен отдельным фильтром.

Роли берутся из `.agents/roles/`. Назначение и статус берутся из задачи. Это сохранённые сведения, а не автоматическое наблюдение за агентами. Изменение Markdown-файла видно при обновлении доски. Второй базы статусов нет.

## 3. Границы

Сервер слушает только `127.0.0.1`, доступен для чтения и раздаёт только файлы интерфейса и проверенные записи задач. Он не раздаёт репозиторий целиком и не входит в публичную витрину. Не публикуйте его как внешний административный сервис без отдельной задачи авторизации и развёртывания. Персональные данные и секреты не должны попадать в записи задач.
